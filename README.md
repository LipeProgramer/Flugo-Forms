# Flugo-Forms
Formulário de cadastro de funcionários estruturado no formato multi-etapas (multi-step), destinado à coleta e organização das informações cadastrais dos colaboradores da empresa Flugo.

# Flugo - Cadastro de Colaboradores

Projeto desenvolvido como desafio técnico.

## Tecnologias

- ReactJS
- TypeScript
- Material UI
- Firebase Firestore
- Vite

## Como rodar localmente

1 - Clone o repositório

2 - Instale as dependências

npm install

3 - Configure o arquivo .env

4 - Rode o projeto

npm run dev

## Deploy

Aplicação hospedada na Vercel

## Funcionalidades

- Multi-step form
- Validação de campos
- Persistência no Firebase
